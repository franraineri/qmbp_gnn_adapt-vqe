## 1. MPS-VQE at N=120: Bond Dimension Validation

### What to prove

"The MPS backend with χ=64 remains exact for HVA p≤2 on 1D TFIM at N=120,
confirming that the pipeline scales to arbitrarily large 1D systems without
accuracy loss from tensor network truncation."

### Method: Bond dimension scaling test (NOT full VQE sweep)

The key insight from the binnacle: at N=40/50/80, DMRG uses χ_actual = 9-15
(far below χ_max=64). For 1D TFIM with gap >> 0, entanglement entropy is
bounded by S ∝ log(ξ) where ξ = 1/gap. At h=6.5, gap=11 → S ≈ 0 → χ=2 suffices.

**Test protocol** (no VQE needed — pure DMRG + MPS evaluation):

```python
# Step 1: DMRG ground truth at N=120
gt = solver.solve(H, lattice, method="dmrg")  # χ_actual will be ~10-15

# Step 2: Build bond-resolved circuit, assign optimal θ from DMRG
# (Use the DMRG ground state to EXTRACT optimal parameters via
#  overlap maximization — or simply use uniform params which give 0.75%)

# Step 3: Compare MPS evaluation at χ=16, 32, 64, 128
for chi in [16, 32, 64, 128]:
    backend = MPSBackend(strategy="aer_mps", chi_max=chi, precision=0.001)
    E_chi = backend.evaluate(qc, H, theta_uniform)
    # If |E_64 - E_128| < 1e-10 → χ=64 is exact at N=120
```

**What this proves**: The bond dimension required by HVA p=1 on 1D TFIM does
NOT grow with N (it's bounded by the entanglement generated by the circuit,
which is O(1) for p=1 at any N in the gapped phase).

## 2. NLCE + GNN-HVA: Thermodynamic Limit

### Overview

Numerical Linked-Cluster Expansion decomposes bulk properties as sums over
finite clusters. For 1D systems, clusters are simply connected intervals of
length L. The GNN-HVA pipeline serves as the cluster solver.

### Architecture

```
NLCE Framework
├── Cluster enumeration (intervals [1..L] for 1D)
├── Embedding constants (=1 for translationally invariant 1D)
├── Cluster solver: GNN-HVA pipeline(N=L, topology=chain_1d)
│   ├── Phase 1: DMRG ground truth
│   ├── Phase 2: VQE θ_opt
│   └── Phase 3: MPNN prediction (optional — direct VQE is fast for L≤10)
└── NLCE sum: P(∞) = Σ_L W(L) where W(L) = P(L) - Σ_{sub} W(sub)
```

### Implementation plan

| Component | Lines | Depends on |
|-----------|:-----:|:----------:|
| `nlce_1d.py` — cluster enumeration + embedding | ~50 | None |
| `nlce_1d.py` — subcluster subtraction (Euler inclusion-exclusion) | ~40 | Above |
| `nlce_runner.py` — orchestrates pipeline calls per cluster | ~80 | Pipeline |
| `nlce_convergence.py` — tracks ΔP(L) vs L, declares convergence | ~30 | nlce_1d |
| **Total** | **~200** | |

### What it proves (thesis value)

**For TFIM 1D** (analytically solvable): Methodological validation.
- NLCE(L=10) should match analytical E₀/site = -(1+h²)^0.5/(2π) × elliptic integral
- Error decays exponentially with L (like e^{-L/ξ} where ξ = correlation length)
- Proves: "GNN-HVA as cluster solver achieves thermodynamic-limit precision"

**For frustrated TFIM 1D (J₁-J₂)** (NOT analytically solvable at all J₂):
- NLCE with your pipeline gives E₀/site for the frustrated model in the TD limit
- No classical method gives this easily for frustrated systems
- **This is the novel contribution**: "First NLCE result for J₁-J₂ TFIM using VQE cluster solver"

### Combined with hardware

The strongest version: execute NLCE clusters (L=6-10) on IBM Torino with PEA-ZNE,
then sum to get thermodynamic-limit energy from HARDWARE data.

```
Hardware NLCE pipeline:
1. For each cluster size L ∈ {4, 6, 8, 10}:
   a. Prepare bond-resolved HVA circuit (L qubits, ≤18 CX → ZNE works)
   b. GNN predicts θ_opt(h, L)
   c. Execute on IBM Torino with PEA-ZNE

```

## 3. Hamiltonian Engineering: Local/Global Split Comparison

### Concept

Decompose the VQE into:
- **θ_x optimization**: Per-site RX angles, optimizable analytically or with
  cheap 1D optimization (each site independent if ZZ coupling is weak)
- **θ_zz optimization**: Per-bond entanglement angles, require quantum resources

For TFIM at h >> J (deep paramagnetic):
- Analytical optimal: θ_x_i ≈ arctan(J·z_i / (2h)) where z_i = coordination number
- θ_zz_k ≈ J/(4h²) (perturbation theory)
- Both are INDEPENDENT of each other to leading order

### Implementation as comparative experiment

```python
# Method A: Full bond-resolved VQE (current — 79 params)
result_full = vqe.optimize(H, qc_br, theta_init_79)

# Method B: Analytical θ_x + VQE only θ_zz (39 params)
theta_x_analytical = np.arctan(J * coord / (2 * h))  # Per site
theta_init_39 = np.zeros(n_edges)  # Only ZZ params to optimize
result_split = vqe.optimize(H, qc_br, concat(theta_init_39, theta_x_analytical),
                            freeze_indices=range(n_edges, n_params))

# Method C: GNN predicts full 79 params (1 forward pass)
result_gnn = evaluate(qc_br, H, theta_pred_gnn)
```

### What this shows

| Method | Params to optimize | Expected ΔE/gap | QPU cost |
|--------|:-----------------:|:---------------:|:--------:|
| Full BR VQE (cold) | 79 | 6.59% (measured) | ~1059 evals |
| Split: analytical θ_x + VQE θ_zz | 39 | ~1-3% (easier landscape) | ~200 evals |
| GNN prediction (0 optimization) | 0 | ~0.75% (uniform baseline) | 1 eval |

**Thesis narrative**: "Hamiltonian engineering reduces the optimization dimension
by 2× but GNN initialization eliminates it entirely. The GNN provides a
more powerful form of 'Hamiltonian engineering' by learning the full spatial
structure from data rather than perturbation theory."
