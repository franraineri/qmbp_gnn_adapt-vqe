  QUALITY METRICS:
  ┌────────────────────────────────────────────────────────────────┐
  │   Delta_E =  |E(theta_pred) - E_exact|                          |
  │   Delta_E / gap  =  |E(theta_pred) - E_exact| / spectral_gap   │
  │                                                                │
  │   < 5%  =  CORRECT PHASE (ground state well-approximated)      │
  │   > 5%  =  FAILURE (circuit cannot express GS at this h)       │
  │                                                                │
  └────────────────────────────────────────────────────────────────┘


  KEY INSIGHT:
  ┌────────────────────────────────────────────────────────────────┐
  │                                                                │
  │  The GNN AMORTIZES the cost of DMRG/VQE:                       │
  │                                                                │
  │  WITHOUT GNN: Each new (h, N) costs 10-1000s of compute        │
  │  WITH GNN:    Train once (O(100) DMRG points)                  │
  │               Then predict forever (O(1ms) per point)          │
